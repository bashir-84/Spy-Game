# جاسوس — نسخهٔ آمادهٔ GitHub Pages

این بسته یک سایت استاتیک کامل است و به نصب وابستگی یا فرایند build نیاز ندارد. فایل `index.html` باید در ریشهٔ مخزن GitHub قرار بگیرد؛ فایل‌های `.js`، `.mjs`، CSS و فونت را هم کنار آن نگه دارید.

## انتشار در GitHub Pages



1. یک مخزن جدید در GitHub بسازید.
2. محتویات همین پوشه را در ریشهٔ مخزن قرار دهید و commit کنید. خود پوشه را به‌عنوان یک پوشهٔ تودرتو آپلود نکنید؛ `index.html` باید در ریشه باشد.
3. در مخزن به **Settings → Pages** بروید.
4. در بخش **Build and deployment**، گزینهٔ **Deploy from a branch** را انتخاب کنید.
5. شاخهٔ `main` و پوشهٔ `/(root)` را انتخاب و ذخیره کنید.
6. پس از پایان انتشار، نشانی GitHub Pages مخزن را باز کنید.

## اجرای محلی

برای اجرای محلی، در همین پوشه دستور زیر را اجرا کنید و نشانی `http://localhost:8000` را باز کنید:

```bash
python -m http.server 8000
```

به‌دلیل استفاده از JavaScript modules، اجرای مستقیم `index.html` با نشانی `file://` ممکن است در مرورگر کار نکند.

## محتویات

- `index.html`: صفحهٔ اصلی
- `app.js` و فایل‌های `.mjs`: منطق بازی، رابط فارسی/انگلیسی، واژه‌ها و تنظیمات
- `style.css`: پوسته‌ها و چیدمان واکنش‌گرا
- `vazirmatn.woff2` و `Vazirmatn-OFL.txt`: فونت فارسی و مجوز آن
- `.nojekyll`: جلوگیری از پردازش خودکار Jekyll در GitHub Pages

سایت داده‌های بازی را در حافظهٔ محلی همان مرورگر و همان دامنه نگه می‌دارد. بنابراین داده‌های ذخیره‌شده روی دامنهٔ فعلی به دامنهٔ جدید GitHub منتقل نمی‌شوند.
